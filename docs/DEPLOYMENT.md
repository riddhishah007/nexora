# Nexora — Permanent Deployment

This repo is ready for one-click permanent deployment.

## Live links (after you deploy)

- **Frontend (Vercel):** `https://nexora.vercel.app` (or your Vercel URL)
  - `https://nexora.vercel.app/workflows` — list
  - `https://nexora.vercel.app/workflows/builder` — React Flow builder
  - `https://nexora.vercel.app/login` — auth
- **Backend API (Render):** `https://nexora-core-api.onrender.com`
  - Health: `https://nexora-core-api.onrender.com/health`
  - Docs: `https://nexora-core-api.onrender.com/docs`
  - OpenAPI: `https://nexora-core-api.onrender.com/openapi.json`
- **GitHub:** `https://github.com/riddhishah007/nexora`

Until you deploy, local links are:
- Frontend: http://localhost:3000
- Backend: http://localhost:8000
- API docs: http://localhost:8000/docs

## Option A — Vercel (frontend) + Render (backend) — Recommended permanent

### 1. Render (backend + worker + postgres + redis) — Blueprint

1. Go to https://dashboard.render.com/blueprints → **New Blueprint Instance**
2. Connect repo `riddhishah007/nexora`
3. Render will read `render.yaml` at root and create 5 services:
   - `nexora-postgres` (Docker `pgvector/pgvector:pg16`)
   - `nexora-redis` (managed Redis)
   - `nexora-core-api` (Docker, `./services/core-api/Dockerfile`)
   - `nexora-worker` (Docker, `./services/worker/Dockerfile`)
   - `nexora-web` (Node, `apps/web`) — *you can skip this if using Vercel*
4. In Render dashboard, set **Environment → Secrets** for `nexora-core-api` and `nexora-worker`:
   - `GROQ_API_KEY` (from https://console.groq.com)
   - `GEMINI_API_KEY` (optional, for real embeddings)
   - `SEARCH_API_KEY` (Tavily, from https://tavily.com)
   - `JWT_SECRET` and `REFRESH_TOKEN_SECRET` are auto-generated by Render (`generateValue: true`), or set your own
5. Set `CORS_ALLOWED_ORIGINS` for `nexora-core-api` to your Vercel URL, e.g. `https://nexora.vercel.app`
6. Deploy → wait for `alembic upgrade head` to run (creates `pgvector` + `jobs` + `security_events`)
7. Copy the **core-api URL** (e.g. `https://nexora-core-api-xxxx.onrender.com`)

### 2. Vercel (frontend)

1. Go to https://vercel.com/new → Import `riddhishah007/nexora`
2. **Root Directory:** `apps/web`
3. **Environment Variables:**
   - `NEXT_PUBLIC_API_URL` = `https://<your-core-api>.onrender.com/api/v1`
4. Deploy — Vercel will run `npm ci && npm run build` (see `apps/web/package.json`)

### 3. Wire them

- In Vercel, ensure `NEXT_PUBLIC_API_URL` points to your Render core-api URL
- In Render, ensure `CORS_ALLOWED_ORIGINS` includes your Vercel URL
- Redeploy both

## Option B — Fly.io (full Docker Compose)

```bash
fly launch --dockerfile services/core-api/Dockerfile --name nexora-core-api
fly launch --dockerfile services/worker/Dockerfile --name nexora-worker
# add fly postgres: fly pg create --name nexora-postgres --image-ref pgvector/pgvector:pg16
# add upstash redis: fly redis create
```

## Option C — Instant temporary (ngrok)

```bash
ngrok http 3000 --host-header=localhost:3000  # frontend
ngrok http 8000 --host-header=localhost:8000  # backend
```

Gives you `https://<random>.ngrok.io` for 2 hours, no deploy needed.

## Environment variables checklist

| Var | Where | Required |
|-----|-------|----------|
| `DATABASE_URL` | Render (from `nexora-postgres` connectionString) | yes |
| `REDIS_URL` | Render (from `nexora-redis`) | yes |
| `JWT_SECRET` | Render (generateValue) | yes |
| `REFRESH_TOKEN_SECRET` | Render | yes |
| `GROQ_API_KEY` or `GEMINI_API_KEY` | Render (sync: false) | one required |
| `SEARCH_API_KEY` | Render | for real search, else mocks |
| `NEXT_PUBLIC_API_URL` | Vercel | yes |
| `CORS_ALLOWED_ORIGINS` | Render core-api | yes |

## Verify after deploy

```bash
curl https://<core-api>/health
curl https://<core-api>/api/v1/agents
# login + builder
curl -X POST https://<core-api>/api/v1/auth/login -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"TestPass123!"}'
```

Frontend will then be live at your Vercel URL with the Workflow Builder at `/workflows/builder`.
